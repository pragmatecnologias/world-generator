# Product Vision — Three.js Game World Creator

## Purpose

Build a browser-based Three.js world creation tool that allows a game creator to visually build environments for games.

The editor must support terrain sculpting, terrain painting, asset importing, manual placement, batch foliage placement, road/track authoring, gameplay markers, environment settings, validation, and export.

## Product Definition

The product is a lightweight custom world editor, similar in spirit to a simplified level editor.

It should let the user create a world from scratch and progressively shape it into a playable game environment.

The user should be able to:

- Create a terrain.
- Sculpt terrain.
- Paint terrain materials.
- Import custom GLB/GLTF assets.
- Place custom assets manually.
- Move, rotate, scale, duplicate, and delete objects.
- Paint foliage and rocks in batches.
- Scatter objects in a defined area.
- Draw roads or tracks.
- Add gameplay markers.
- Save and reload projects.
- Export the world to a game.
- Validate the world.

## Target User

The main user is a game creator who wants direct control over world creation without manually writing every object position in code.

The tool should be useful for:

- Off-road racing games.
- Adventure games.
- Biblical/ancient world scenes.
- Medieval/fantasy scenes.
- Prototype-to-production game maps.

## What This Is Not

This is not:

- A random noise terrain demo.
- A simple Three.js scene viewer.
- A static map preview.
- A generic asset gallery.
- An AI-only world generator.
- A pretty screenshot generator.

## What This Must Become

This must become a practical environment authoring tool where the user can create usable, exportable game worlds.

The most important concept is control plus productivity:

- Manual precision when needed.
- Batch automation when repetitive work is needed.
